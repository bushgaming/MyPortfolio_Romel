# Minimal Professional Portfolio Template

A responsive portfolio website for web design and development commissions.

## Files
- `index.html` — page content and editable placeholders
- `style.css` — layout, colors, typography, and responsive styles
- `script.js` — mobile navigation and automatic footer year

## Run it
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Customize before publishing
1. Search for `Your Name` and replace it with your name or brand.
2. Replace the About Me, services, projects, experience, and skills with accurate information.
3. Replace `hello@example.com` with your real contact email in both the email link and visible text.
4. Update the LinkedIn, GitHub, and Facebook links to your own profiles.
5. Replace the three sample project previews with your real screenshots and project links.
6. Update the page title and meta description near the top of `index.html`.

The sample project previews are CSS illustrations, not real portfolio projects. The contact button opens the visitor's email application through a `mailto:` link; it does not submit a form or store messages.
